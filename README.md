# PAIMX Assistant releases

Signed, notarised installers for the PAIMX Assistant worker — the program that
lets your own computer answer your PAIMX Assistant. Download the latest from
[Releases](https://github.com/zhengst-king/paimx-assistant-releases/releases). `channels/stable.json` is the
manifest the PAIMX hub and the worker's update check read; it is built by
`packages/assistant-worker/package-macos.mjs` in paimx-platform.
